# Scott Li Portfolio — Updated

## Run locally
1. Open this entire folder in Visual Studio Code.
2. Install the Live Server extension if necessary.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Visit **Projects** to test JSON loading, filters, and project details.
5. Toggle **Dark** in the navigation; the theme should persist across pages.

Do not open `projects.html` with a `file://` URL: `fetch()` requires a local HTTP server.

## File locations
- HTML pages: project root
- CSS: `css/style.css`
- JavaScript: `js/script.js`
- Project data: `data/projects.json`
- Avatar: `images/avatar.svg`

## Before submission
- Replace the placeholder email and LinkedIn profile in `contact.html`.
- Confirm education, dates, employment details, project descriptions, and certifications are accurate.
- Add project repository URLs to `data/projects.json` if available.
- Bootstrap, Bootstrap Icons, and Google Fonts are loaded via CDN and require internet access.

This is a static portfolio; the contact page provides links, not a working contact form.
